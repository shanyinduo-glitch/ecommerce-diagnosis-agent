# 项目输入数据

`raw/public/` 是课程公开模拟数据的工作副本，共三个独立案例，各有订单明细、商品、流量三张 CSV。原件保留在根目录的课程资料包。

默认对比期为 2026-09-01 至 09-14，分析期为 09-15 至 09-28。金额单位为元，金额已经是整条明细金额，不再乘数量。读取 UTF-8 BOM，编号保持字符串。金额计算转换为整数分。

`manifests/public.json` 保存原始来源及 SHA256。每次运行另外登记输入哈希。

Agent 仅加载用户选择案例的三个指定 CSV，不读取参考答案、生成脚本或历史项目。参考答案单独存于 `evaluation/references/`。模型只能通过注册工具查询内存数据，没有通用文件或 Python 执行接口。

准备命令：`.venv\Scripts\python.exe scripts\prepare_data.py`。此命令拒绝覆盖内容不同的已存在业务 CSV。
