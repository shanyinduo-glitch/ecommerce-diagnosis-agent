# 电商销售下降分析 Agent 资料与项目规划

整理日期：2026-10-26。适用范围：课程大作业题目二，八人小组，两周完成。

本目录是资料包与实施规划，不是已经实现的 Agent。原始课程材料保持不变。

## 阅读顺序

1. `01_课题说明/课题二正式说明摘录.md`：正式要求摘录，是验收依据。
2. `01_课题说明/数据说明与验收清单.md`：数据字典、计算口径、数据质量规则与必做清单。
3. `04_项目规划/项目结构与实现方案.md`：建议技术方案、目录、模块接口与交付内容。
4. `04_项目规划/八人分工与两周排期.md`：角色、具体任务、交接物与排期。
5. `04_项目规划/评测方案与提交清单.md`：评测定义、恢复场景与最终报告安排。

## 目录用途

| 目录 | 内容 | 使用方式 |
|---|---|---|
| 01_课题说明 | 正式摘录、数据说明、验收要求 | 全员先读 |
| 02_公开数据 | 三个案例，各三张 CSV | Agent 的业务输入 |
| 03_开发评测参考 | 数据生成脚本、公开答案 | 开发核对与独立评测使用 |
| 04_项目规划 | 结构、实现内容、八人分工、排期、评测 | 小组协作执行依据 |
| 05_原始资料备份 | 完整正式 Word | 回查原文，含题目一但不要求实现 |

已排除 MovieLens 数据准备脚本、无关下载说明、macOS 元数据文件。公开数据从原压缩包直接提取，没有改动。参考答案与业务输入分目录存放，运行 Agent 时只开放选定案例的三张 CSV；目录分开本身不构成访问控制，实现时还需限制工具可访问路径。

## 数据准备

三组数据已解压，可以直接使用，无须重新生成。需要复现时，从本目录执行：

```powershell
python .\03_开发评测参考\generate_ecommerce_data.py --mode public --output .\临时生成数据 --seed 20261018
```

生成脚本需要 Python 3.10+，只使用标准库；输出目录必须不存在或为空。生成出的参考答案不要作为 Agent 的输入。
